## Orientação em destaque

As atividades devem ser resolvidas com foco em algoritmo e lógica de programação. Deve ser disponibilizada em um github público, para que eu possa avaliar. Não devem ser usadas bibliotecas externas ou funções prontas que já resolvam o problema automaticamente. Por exemplo, na atividade de soma dos elementos, a ideia não é usar sum(arr), arr.sum() arr.sort() ou qualquer função equivalente que já faça a soma ou ordenação sozinha. O objetivo é construir a lógica passo a passo, utilizando variáveis, condicionais, laços de repetição, funções, listas/arrays, strings, matrizes e acesso por índice. Também não é necessário criar sistema completo, cadastro, banco de dados ou interface. O foco é resolver corretamente os problemas propostos por meio do raciocínio algorítmico.
